# Nicholas Deway — Portfólio

Portfólio pessoal desenvolvido com **Next.js 15**, apresentando experiências profissionais, projetos freelancer com documentação técnica detalhada, diplomas e formas de contato.

## Features

- **Página inicial** com apresentação, stack, experiências, cursos e contato
- **Seção de projetos** com página de detalhe por projeto contendo:
  - Visão geral, galeria de imagens, diagrama de arquitetura (Mermaid)
  - Banco de dados com schema SQL e entidades C#
  - API / Endpoints com paginação
  - Segurança, configuração, deploy e aprendizados
- **Navegação lateral** com dots de scroll e índice por seção
- **Tema claro/escuro** com transição via View Transitions API
- **Animações** com Framer Motion e CSS

## 🛠️ Stack

| Camada        | Tecnologia                                  |
|---------------|---------------------------------------------|
| Framework     | Next.js 15 (App Router)                     |
| Linguagem     | TypeScript 5                                |
| Estilização   | Tailwind CSS 4                              |
| Componentes   | shadcn/ui + Radix UI                        |
| Animações     | Framer Motion, tailwindcss-animate          |
| Diagramas     | Mermaid.js                                  |
| Fonte         | Geist (Google Fonts via `next/font`)        |
| Tema          | next-themes                                 |

## Como rodar

> Requisitos: **Node.js 18+** e **npm**

```bash
# Instalar dependências
npm install

# Rodar em desenvolvimento
npm run dev

# Build de produção
npm run build

# Iniciar em produção
npm start
```
